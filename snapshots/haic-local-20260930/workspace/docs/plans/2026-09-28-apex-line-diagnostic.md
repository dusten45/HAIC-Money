# 공개 상위권 주행선 모방: 첫 픽셀 진단

2026-09-28 공개 1차 모의평가 트랙 3 영상에는 현재 1위 바이브코더(T15)와 3위 탑저그예요(T17)의 과거 주행이 보인다. 코너에서 도로 중심을 고정적으로 따르지 않고 가로 폭을 쓰는 장면을 관찰했다. 2위 외국인은 영상에 없고, 세 팀의 최신 제출 주행선·조작값은 확인되지 않았다. 이 관찰은 가설의 출처이며 성능 근거가 아니다.

첫 후보 `ApexLineAgent`는 기존 안정 조향과 고속 학습 페달을 유지한다. 픽셀에서 일곱 도로 행이 보이고 장애물이 없고 빠른 페달 사용이 허용될 때, 먼 도로 중심이 향하는 코너 안쪽으로 가까운 도로 반폭의 25%만큼 목표점을 옮긴다. 조향 이득 0.022는 현 도로 제어기의 픽셀 조향 이득이다. 보정 전후 행동은 유한하고 조향 범위 [-0.7, 0.7]을 지킨다. 이 변경은 최신 경쟁 차량의 정확한 경로를 복제한다는 주장이 아니라, 영상에서 관찰한 가로 위치 변화를 픽셀만으로 구현한 첫 메커니즘이다.

첫 진단은 **이미 소비된 tune 1/184 한 셀**이다. 등록된 `benchmark_corridor_diagnostic` 로컬 프로필에서 selected full-road-guard, 이전 fast-pedal-stable-steer, 새 apex-line 세 팔을 같은 Linux/Python 3.11 CPU 환경과 2,000 decision 상한으로 주행한다. 체크포인트 두 개는 코드에 지정된 경로와 정확한 SHA-256을 실행 때 재검사한다. 전체 행동 trace, 실제 결승선 통과, 랩타임, 진행률, 속도, 충돌·손상, 지연을 기록한다. `apex_decisions>0`이고 영상 기반 도로 안쪽 조향이 관찰되어야 메커니즘이 활성화된 것으로 본다. 미완주 또는 명백한 불안정이 나오면 새 tune을 열지 않는다. 이 한 셀은 독립 성능 개선의 근거가 아니다.

활성화되고 급격한 실패가 없으면 별도 계획에서 트랙 1·2·3 × 새 tune seed 296–299의 동일 12셀/arm을 사전 등록해 완주율 우선으로 비교한다. 그 이전에 사용한 260–295는 새 검증으로 재활용하지 않는다. held-out와 confirmation은 tune 성적과 후보 고정 뒤 별도 등록한다. 대회 사이트 업로드, 공식 제출, 모델 확정은 하지 않는다.
