# Fixed teacher on a new TRAIN block with matched completion gate

The frozen geometry-coast teacher on TRAIN 5000–5003 finished 11/12 versus control 11/12 and was faster on finished laps, but its preregistered absolute 12/12 gate failed. Both arms crashed at the same track 3 seed 5000 with five collisions and 92% progress. That run remains `REVISE`; these cells cannot be reused as fresh evidence. An absolute perfect-finish gate conflated a shared obstacle failure with teacher-specific harm. This new plan prospectively uses the competition's matched completion-first criterion on disjoint TRAIN cells.

Keep the exact teacher source, stable-risk pixel control and checkpoint unchanged. Assign tracks 1–3 × seeds 5004–5007 to TRAIN; project design/run manifests did not contain these identities at registration. Run each arm on all twelve cells with 2,000 decisions and 1,800 seconds maximum. Record full traces, valid finish, progress, collisions, damage, invalid actions, gas/coast interventions, action latency and duration. This remains teacher feasibility only, never submission-candidate score.

Advance to demonstration collection only if the teacher has **at least as many valid finishes as control**, no candidate-only nonfinish, zero invalid actions, and a median finished lap at least **3% faster on jointly completed paired cells**. Any candidate-only nonfinish rejects it regardless of aggregate count. This gate applies only to the new 5004–5007 block and does not change the older 5000–5003 outcome. A successful teacher still requires a separately trained pixel-only student and independent candidate evaluation. No site upload, model confirmation or official submission is included.
