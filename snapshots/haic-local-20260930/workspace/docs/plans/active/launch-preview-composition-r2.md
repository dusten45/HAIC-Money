## 고정할 수정

`ObstacleFullRoadGuardAgent → LaunchSurgeAgent → AnticipatoryBendAgent`는 유지한다. 마지막 속도 wrapper에서는 직선 추가 가속과 중복 선행 조향을 없애고, 기존 `SpeedCoupledPreviewAgent`와 동일한 픽셀 굴곡·현재/이전 프레임 일관성·속도 `>45`·굴곡 절댓값 `>=7` 조건일 때만 gas 0과 brake 최소 0.07을 적용한다. 장애물 시에는 기본 장애물 대응을 보존한다. 원본 출발 가속 임계값과 앞보기 조향 임계값은 변경하지 않는다. 새 코드는 위치·지도·환경 상태를 추론에 사용하지 않는다.

## 판정

새 ZIP의 출발 가속 횟수와 앞보기 조향·커브 제동 활성화를 소비된 2900–2903에서 먼저 확인한다. 직선 추가 가속은 0이어야 한다. 이 조건에서도 후보만 미완주하면 수정본을 기각하고 새 tune을 열지 않는다. 진단이 통과하면 새 tune 7012–7015, held-out 7016–7019, confirmation 7020–7023을 순서대로 예약하고 실행 전 다른 V2 run/계획과 중복을 확인한다. 각 블록은 트랙 1–3 × 시드 4개, 두 ZIP 각 12셀, 최대 2,000 decision, 2 CPU/2 GiB, 1,800초다. 완주율을 최우선으로 판정하며 동률만 완주 시간과 후순위 지표를 비교한다. 사이트 업로드·공식 제출·모델 확정은 포함되지 않는다.
