# 출발 가속·앞보기 조향 ZIP과 현재 선택 ZIP의 직접 비교

## 고정 입력과 이유

출발 가속·앞보기 조향 ZIP SHA-256 `533c3a74f43313ace925998830d3c9b948a2185d4866e761025978f44c1542d7`은 앞선 새 tune, held-out, confirmation에서 출발 가속만 쓴 ZIP과 비교해 각각 12/12 대 12/12, 12/12 대 11/12, 12/12 대 12/12 완주했다. 마지막 중앙시간은 24.18 대 24.38초였다. 그러나 출발 가속만 쓴 ZIP은 다른 소비된 진단에서 현재 선택된 full-road-guard ZIP보다 완주가 적었다. 그래서 이 후보를 현재 선택 ZIP SHA-256 `5c55670ab5aef4bf64115909792650a5e76bc3576a64f3aaeb3780efabc18e40`과 직접 같은 셀에서 확인한다.

## 등록 비교

`training.compare_launch_surge_package`의 정확한 ZIP 추출 비교를 사용한다. 새 tune은 트랙 1·2·3 × seed 7040–7043, 각 팔 12셀, 셀당 최대 2,000 decision이다. 후보가 결승선 통과율에서 열세면 거절한다. 같으면 완주 중앙시간, 평균 미완주 진행률, P90 시간, 충돌, 손상, act p95 순으로 본다. 첫 10% 도달 시각과 gas·속도, 앞보기 조향 활성 횟수는 원인 진단으로만 보며, 이 comparator는 조향 활성 횟수를 직접 수집하지 않으므로 앞선 정확한 ZIP 확인 기록을 참조한다. 대조군보다 앞서야 보류 seed 7044–7047을 열 수 있다. 확인 seed 7048–7051은 별도다. 실행 직전에 V2 manifest와 계획 예약이 겹치지 않는지 다시 확인한다.

로컬 Linux Python 3.11 CPU, 2 CPU/2 GiB, 블록당 24 episode, 1,800초를 넘지 않는다. 추론은 ZIP 내부의 픽셀과 상속 행동만 사용한다. 계획 해시마다 사용자 2026-09-29 상시 로컬 승인을 인용해 설계·실행 이벤트를 별도 기록한다. 공식 사이트 업로드·제출·모델 확정은 포함하지 않는다.
