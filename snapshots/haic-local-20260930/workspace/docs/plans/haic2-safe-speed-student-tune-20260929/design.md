Its validation activation was high, which may be indiscriminate acceleration rather than useful road-speed selection. Test this directly: compare the exact checkpoint against the unchanged stable-risk pixel control on tracks 1–3 × previously unused TUNE seeds 5200–5203. Both arms run all twelve matched cells with the same official-compatible local environment, 2,000 decisions per episode, 1,800 seconds maximum. Capture full traces, valid finish and lap time, incomplete progress, collisions/damage, invalid actions, gas interventions, latency and duration. Short road departure is a diagnostic, not an automatic rejection if the car validly finishes.
